# 🌍 Overview

**EcoTrack AI** is a modern full-stack sustainability platform designed to help organizations and individuals understand, manage, and improve their environmental impact.

The platform combines:

- 🌱 Sustainability & carbon tracking
- 🤖 AI-powered sustainability recommendations
- 📊 Interactive analytics
- 🌍 Green initiative discovery
- 🌳 Environmental project funding
- 💳 Stripe-powered subscriptions
- 🔐 Secure authentication
- 📈 Data-driven dashboards

EcoTrack transforms sustainability management into a simple workflow:


# ❗ The Problem

Sustainability management can become difficult when environmental data is maintained manually or spread across multiple systems.

Organizations and users often need to:

* Track environmental impact
* Organize sustainability records
* Understand environmental performance
* Identify areas for improvement
* Receive actionable sustainability recommendations
* Discover meaningful green initiatives
* Support environmental projects
* Manage sustainability-related subscriptions

The main challenge is not simply knowing the environmental impact.

The bigger question is:

> **What should we do next to improve it?**

EcoTrack AI addresses this challenge by combining structured sustainability tracking with AI-powered recommendations and actionable improvement plans.

## 🤖 AI Sustainability Advisor

EcoTrack integrates **Google Gemini AI** to analyze available sustainability data and provide practical recommendations.

The AI advisor can generate:

Instead of providing only generic sustainability information, the AI advisor uses the user's available application data to generate more relevant recommendations.

# 🔌 API Overview

## Items API

### Get Items

```http
GET /api/items
```

### Search / Sort / Pagination

```http
GET /api/items?sort=impact&page=1&limit=8
```

### Item Endpoints

| Method   | Endpoint         | Description                            |
| -------- | ---------------- | -------------------------------------- |
| `GET`    | `/api/items`     | Get, search, filter and paginate items |
| `GET`    | `/api/items/:id` | Get a single item                      |
| `POST`   | `/api/items`     | Create a new item                      |
| `PATCH`  | `/api/items/:id` | Update an item                         |
| `DELETE` | `/api/items/:id` | Delete an item                         |

# 🚀 Getting Started

## Prerequisites

Make sure the following are installed:

* Node.js 20+
* npm
* Git
* MongoDB Atlas account
* Google Gemini API key
* Stripe account
* Google OAuth credentials

---

# 💻 Frontend Setup

Clone the frontend repository:

```bash
git clone <your-frontend-repository-url>
cd ecotrack-client
```

Install dependencies:

```bash
npm install
```

Create:

```text
.env.local
```

Add:

```env
MONGODB_URL=your_mongodb_connection_string

BETTER_AUTH_SECRET=your_better_auth_secret

BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_BETTER_AUTH_URL=http://localhost:3000

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

NEXT_PUBLIC_API_URL=http://localhost:5000
```

Start the development server:

```bash
npm run dev
```

Frontend:

```text
http://localhost:3000
```

---

# 🖥️ Backend Setup

Clone the backend repository:

```bash
git clone <your-backend-repository-url>
cd ecotrack-server
```

Install dependencies:

```bash
npm install
```

Create:

```text
.env
```

Add:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

GEMINI_API_KEY=your_gemini_api_key

STRIPE_SECRET_KEY=your_stripe_secret_key

CLIENT_URL=http://localhost:3000
```

Start the development server:

```bash
npm run dev
```

Backend:

```text
http://localhost:5000
```

# 🛡️ Security

EcoTrack follows several security-focused practices:

* Environment variables for sensitive credentials
* Secure authentication sessions
* Protected dashboard routes
* Server-side validation
* Subscription-aware access control
* Stripe webhook handling
* CORS configuration
* Database connection management
* No secret keys committed to source control
